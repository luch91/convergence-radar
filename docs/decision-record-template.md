# Decision Record Template

Create a copy of this file in `.local/decisions/` for a working decision. That directory is ignored by Git.

```markdown
# Decision: <short title>

Date: YYYY-MM-DD
Status: proposed | accepted | rejected | replaced
Owner: <name or team>

## Context

State the problem and the applicable limits.

## Decision

State the selected action.

## Reasons

State the evidence and the trade-offs.

## Consequences

State what will change, the risks, and the follow-up work.

## References

List links, test results, or transaction references.
```
